Tipos de estilos en CSS

Estilos en línea

Estos estilos se van a agregar directamente en el elemento HTML mediante el atributo style

Este párrafo tiene estilos en línea

Estilos internos

Estos estilos se agregan en el mismo archivo HTML, dentro de la etiqueta <head> y para agregralos se utiliza el elemento: <style>

Estilos externos

Estos estilos son los que se recomienda utilizar, ya que ofrecen modularidad, fácil mantenimiento, orden, eficiencia, entre otras ventajas, para agregar una hoja de estilos externa, dentro de la etiqueta <head>, se utiliza el elemento <link> donde se especifica la ruta de nuestra hoja de estilos
