RESUMEN HTML: PRINCIPALES CONCEPTOS Y ETIQUETAS

Esta página va a resumir los principales conceptos y etiquetas vistas en la clase de programación web 1, en el módulo HTML

Conceptos principales HTML

HTML

Lenguaje de marcado de hipertexto es un lenguaje de marcas que se utiliza para estructurar sitios web

Elemento HTML

Un elemento HTML es la unidad básica de estructura y contenido en una página web, y está compuesta de :

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head>

Es una etiqueta que se utiliza para comunicarse con el navegador através de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts

Etiqueta <Body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página web

Contenedores semánticos

<Header> Etiqueta utilizada para el contenido introductorio de una página web, puede contener el logo, el menpu de navegación principal, el nombre de la empresa, etc.
<Nav> Etiqueta utilizada para el menú de navegación principal, suele contener enlaces a otras páginas relacionadas o navegar por la página principal, no debe haber más de una en la página
<Main> Etiqueta única de una página web cuyo propósito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocará el contenido princpal de nuestra página
<Section> Es una etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para divir a una página web en secciones y agrupar contenido relacionado
<Article> Es una etiqueta que se utiliza para agrupar contenido autónomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<Footer> Es una etiqueta que normalmente se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria
<Aside> Esta etiqueta representa una sección de la página web cuyo contenido no está directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros artículos relacionados, etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras páginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/1234567890"
Este valor envía un WhatsApp a un número especificado
href="mailto:example@gmail.com"
Envía un correo a un mail específico
